## 用 JangoPay 构建更清晰的支付流程

通过收款链接接收稳定币与加密货币付款，将支付状态接入业务系统，在统一的商户后台管理收款、资产与客户数据。

| 快速开始收款 | 连接业务系统 | 管理支付运营 |
| :--- | :--- | :--- |
| **收款链接** — 创建付款页面并分享给客户，无需从零开发结账页。 | **API 与 Webhook** — 将订单创建、收款状态与通知连接到网站、应用或业务后台。 | **商户工作台** — 查看收款状态、币种余额、资产转出与客户活动。 |
